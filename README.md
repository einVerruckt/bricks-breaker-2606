# Brick Breaker Assignment

This project was completed as a class assignment focused on working within an existing Brick Breaker codebase.

## Assignment Scope

The purpose of this assignment was to implement the specific changes and requirements outlined in the assignment instructions. Development was limited to the areas required by those parameters.

The existing core game logic was not modified or redesigned. Any changes made were only those necessary to satisfy the requirements of the assignment.

## Notes

* Created for educational purposes.
* Based on a pre-existing Brick Breaker project/codebase.
* Changes were made according to the provided assignment requirements.
* Core gameplay logic and functionality were left unchanged unless specifically required by the assignment.
* This repository represents coursework rather than a complete original game project.
